# Entity-Relationship Diagram

## Overview
The Entity-Relationship Diagram (ERD) is a visual representation of the entities within a system and the relationships between them. It is used to model the data structure and relationships in a database.

The next sections will provide an overview of the entities, their attributes, and the relationships between them in the context of the SewaKost application.

## Polymorphic Relationships
Unlike standard relationships, polymorphic relationships allow a model to belong to more than one other model on a single association. In the SewaKost application, polymorphic relationships are used for review images, where both kost reviews and room reviews can have associated images.

| Relationship | Parent | Child | Type | Foreign Key | Description |
|--------------|--------|-------|------|-------------|-------------|
| Review → Review Images | kost_reviews / room_reviews | review_images | Morph Many | (review_type, review_id) | Satu tabel gambar digunakan oleh dua jenis review. Treview_type + review_id merupakan foreign key secara konseptual (polymorphic reference), tetapi tidak dapat diimplementasikan sebagai foreign key constraint native pada MySQL/PostgreSQL karena target tabelnya bersifat dinamis |
